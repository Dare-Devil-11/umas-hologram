📡
pixel-tracker.js NEW
Drop before </body> on any page. Auto-fires 15 event types. Fires simultaneously to your Apps Script endpoint, Facebook Pixel, GA4, and LinkedIn if configured. One config object at the top — no code changes needed per site.
📊
apps-script-receiver.js NEW
Google Apps Script Web App. Receives POST events, writes all 24 columns to "Pixel Events" sheet, maintains a "Meta" summary tab with event counts and last-seen timestamps. Supports ?action=csv for direct CSV export and ?action=meta for event summary JSON. Auto-trims to 50,000 rows.
⬇️
download-and-sync.sh NEW
Fetches CSV from Apps Script → saves events-latest.csv locally → archives a timestamped copy → uploads to gdrive:AI-OS/pixel-tracker/ replacing the previous version. Run manually or add to cron for scheduled exports.
📋
embed-snippet.html NEW
Copy-paste ready block with GOAT_PIXEL_CONFIG. Set your Apps Script URL, optional FB/GA4/LinkedIn IDs, and drop it before </body>. Includes example manual event calls for Purchase, TrialStart, and QuoteRequest.
4-Step Setup
1. Deploy Apps Script
sheets.google.com → New Sheet → Extensions → Apps Script → paste apps-script-receiver.js → Deploy → Web App → Access: Anyone → copy URL
→
2. Configure & Embed
Set GOAT_PIXEL_CONFIG.endpoint = your URL. Optionally add fb_pixel_id, ga4_id. Drop embed-snippet.html before </body> on target pages.
→
3. Events Flow In
Every click, scroll, form submit, phone call → POST to Apps Script → row appended to "Pixel Events" sheet in real time. 24 columns, auto-trimmed to 50k rows.
→
4. Export & Sync
bash download-and-sync.sh → events-latest.csv saved locally + uploaded to Google Drive. Or hit ?action=csv directly from any browser to download on demand.
