⌘ APPLE UNIVERSAL CONTROL

Universal Control

One keyboard + trackpad controlling multiple Macs and iPads. Push cursor to screen edge — it jumps to the next device.

Setup Timeline

Step 1 — Requirements
Confirm Both Devices Ready
macOS 12.3+ · iPadOS 15.4+ · Same WiFi router · Bluetooth ON · Same Apple ID · Screen sharing OFF
Step 2 — Mac Settings
Enable on Mac
System Settings → Displays → Advanced → Turn ON both toggles (Allow pointer + Push through edge)
Step 3 — iPad Settings
Enable on iPad
Settings → General → AirPlay & Handoff → Turn ON Handoff · Wake iPad and unlock it
Step 4 — Test
Push Cursor to Edge
Slowly push cursor past the right (or left) edge of your Mac screen — it slides onto the iPad. Type on Mac keyboard. Drag files across.
Step 5 — Your Setup
Position Devices
System Settings → Displays → drag device thumbnails to match physical layout. Mac left · iPad right = push cursor right to jump to iPad.

Commands + Actions

Type on another deviceMove cursor there → type on Mac keyboard normally keyboard follows cursor
Drag file cross-deviceDrag → push to edge → keep holding → drop on other device cross-device drag
Copy/Paste cross-device⌘C on Mac → move cursor to iPad → ⌘V — clipboard shared universal clipboard
Rearrange layoutSystem Settings → Displays → drag device thumbnails to match physical positions
Manual disconnectMenu bar → Control Center → click device name → Disconnect
Lock cursor to one MacToggle OFF "Push through edge" (the setting you screenshotted)

Troubleshooting

Not connecting
Both on same WiFi? Bluetooth ON? Same Apple ID? Try toggling Bluetooth off/on on both devices.
Cursor won't cross
System Settings → Displays → Advanced → confirm toggles are ON. Check device layout matches physical positions.
Works on hotspot?
No. Requires same local WiFi router. Hotspot does not count. Switch to work or home WiFi.
iPad not showing
iPad: Settings → General → AirPlay & Handoff → turn ON Handoff. iPad must be awake + unlocked.
Drag/drop not working
Drag slowly — pause at the edge and wait for cursor to pull through before releasing. Fast swipes miss.
